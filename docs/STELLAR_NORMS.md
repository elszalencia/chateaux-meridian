- 2026-10-19 · storage · Instance storage shares one entry capped near 64 KB: no per-plan data there. Confidence: high
- 2026-10-24 · rent · Testnet `live_soroban_state_size_window` is ~4.011 GB, above `soroban_state_target_size_bytes` 4,000,000,000 (`rent_fee1_kb_soroban_state_size_high` 10000, growth factor 5000). Above target, rent on new entries is steep: simulating `upload_contract_wasm` of the 36,816-byte payment_plan Wasm (sha256 85d78e4b…) returned minResourceFee 4,606,913,140 stroops (460.7 XLM), and 482.5 XLM an hour later. A transaction fee is a uint32 of stroops (max 429.5 XLM), so no single transaction can carry the upload: the live upgrade to this Wasm is **blocked** until the state size drops or the Wasm shrinks (contract spec doc strings are part of the Wasm). `stellar contract optimize` saved 0 bytes. Small writes (create_plan, deposits, releases) were unaffected. Services now raise `ChainError` `FeeTooHigh` and `deploy:testnet` defers the upgrade. Source: `stellar network settings --internal`, simulateTransaction · Confidence: high (tested)
- 2026-10-25 · rent · Upload fee measured by simulation on testnet (live state ~4.0107 GB, still above the 4 GB target): payment_plan Wasm 36,816 B → 727.7 XLM; the same contract with every doc comment removed, 27,868 B → 697.1 XLM; the shipped 31,104 B Wasm (8d2a4402…) → 738.5 XLM an hour later. A 24 % smaller Wasm is only ~4 % cheaper, so the fee is dominated by a size-independent part of the rent and grows with the network state from day to day (460.7 XLM on 2026-10-24). Shrinking the Wasm cannot bring the upload under the 429.5 XLM uint32 fee limit while the state is above target; the live contract stays on a28d240c… until the network fee falls. Doc comments on public items are compiled into the `contractspecv0` custom section (15,059 of 36,816 B before), so they are kept to one line and the full text lives in docs/CONTRACT.md. Source: simulateTransaction, `stellar network settings --internal` · Confidence: high (tested) · Extends: 2026-10-24 rent entry
